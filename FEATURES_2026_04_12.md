### 3. ✅ **Fotos-Anzeige korrigiert**

**Das Problem:**
- Backend gab relative URLs `/uploads/photo_xxx.jpg` zurück
- Frontend war auf `localhost:3001` und konnte nicht auf `localhost:3000/uploads` zugreifen

**Die Lösung:**
- `frontend/app/entries/new/page.tsx` angepasst
- Photo-URLs werden zu **absoluten URLs** konvertiert
- Format: `http://localhost:3000/uploads/photo_xxx.jpg`
- Fotos zeigen korrekt in Tabelle und Einträgen

**Code:**
```typescript
const absoluteUrl = json.url.startsWith('http') 
  ? json.url 
  : `http://localhost:3000${json.url}`;
```

### 4. ✅ **Dropdown-Bug beim neuen Entry gefixt**

**Das Problem:**
- Auto-Refresh alle 30 Sekunden reset die ausgewählte Element-ID
- Dropdown "springt" immer wieder auf erstes Element
- Nicht alle Elemente wurden angeboten

**Die Lösung:**
- `frontend/app/entries/new/page.tsx` angepasst
- `loadElements()` erhält Parameter `forceSetFirstElement`
- Initial Load: `true` → Setzt erstes Element
- Auto-Refresh: `false` → Lädt Elemente ohne Selection zu ändern
- **Bug Fix:** Element-Select springt nicht mehr herum

**Code:**
```typescript
useEffect(() => {
  loadElements(true); // Initial: true
  const interval = setInterval(() => loadElements(false), 30000); // Auto: false
  return () => clearInterval(interval);
}, []);
```
